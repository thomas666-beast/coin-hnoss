# Coin::Hnoss

Exact monetary values for Perl. A value-object library for handling money
without floating-point errors, inspired by the Money pattern (Martin Fowler)
and `moneyphp/money`.

The name is Old Norse: **Hnoss** is a goddess of treasure and precious things.

## Status

Early development. See `Changes`.

## Running tests

    cpanm --installdeps .
    perl Makefile.PL
    make test
